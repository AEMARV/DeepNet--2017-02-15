# DeepNet

Opened 2017-02-15. The default branch is `BRelu`.

MatConvNet-style CIFAR training in MATLAB. `layers/` adds a stochastic ReLU (`vl_nnstochrelu.m`) and a bivariate ReLU (`em_nnbirelu.m`) beside the training loop in `cnn_train.m` and `cnn_cifar.m`.
